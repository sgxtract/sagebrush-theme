# Changelog

## [0.2.0] - 2026-10-07

### Changed

- Reworked the palette so neighboring syntax colors are easier to tell apart, while keeping the original background and foreground
- Keywords, tags, and Markdown headings are now purple; `this`, decorators, and errors use a clearer red
- Strings, functions, and numbers nudged apart (green, teal, and gold)
- Added blue for types and links, and orange for properties

### Added

- Full workbench colors: tabs, panels, widgets, inputs, buttons, notifications, and git decorations
- Integrated terminal colors and bracket pair colors
- Full Markdown styling: bold, italic, inline code, links, quotes, lists, and code fences
- Extension icon
